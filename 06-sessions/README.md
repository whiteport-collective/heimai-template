# Sessions

The handovers between sessions: `<user>/<agent>/` for a handover to one agent from one person, `all-users/<agent>/` for one any person may take. The file name starts with the session's time (`YYYY-MM-DD_HH-MM-<user>-…`). Handovers are never deleted; in someone else's folder, only add a new file.

The personal part of each handover lies in the person's private Heim, never here.
