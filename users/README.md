# Users

One folder per person who works in this Heim, named after their GitHub username in lowercase. Shared and professional: the team, partners and the client may read it.

- `user.md`: the person's role here.
- `soul.md`: how we work together in this Heim: roles, agreements, conventions with the team and the agents.
- `objectives.md`: what the person wants to achieve here.

The person's own working style and what they have delivered live in their private Heim, which follows them. A new person's folder is made from `_template/` (`heim-scaffold add-person`). Never write in someone else's folder.
